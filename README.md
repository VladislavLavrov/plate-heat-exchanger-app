# Испытание пластинчатого теплообменника (Web)

Виртуальная лабораторная работа для учебного исследования эффективности рекуперативного пластинчатого теплообменника.

## 1) Запуск (без установки ПО)
**Вариант А (самый простой):** откройте `index.html` двойным щелчком в браузере.

**Вариант Б (для разработки в VS Code):**
1. Откройте папку проекта в Visual Studio Code
2. Установите расширение **Live Server**
3. ПКМ по `index.html` → **Open with Live Server**

## 2) Что можно исследовать
- Сравнение **прямотока** и **противотока** по эффективности ε
- Влияние расхода горячего контура Vг на эффективность
- Влияние температуры входов T1 и T3
- Влияние «качества теплопередачи» k (условно: чистота пластин, турбулизация, контактные сопротивления)
- Роль теплопотерь (модельно) — чтобы увидеть расхождение Qг и Qх

## 3) Переменные и обозначения
- **T1** — горячий теплоноситель на входе (°C)
- **T4** — горячий теплоноситель на выходе (°C)
- **T3** — холодный теплоноситель на входе (°C)
- **T2** — холодный теплоноситель на выходе (°C)
- **Vг** — расход горячего контура (л/мин)
- **Vх** — расход холодного контура (л/мин), принят постоянным **1,2 л/мин**
- **F** — площадь поверхности теплообмена, принята **0,12 м²**
- **Qг** — теплота, отдаваемая горячим контуром (Вт)
- **Qх** — теплота, полученная холодным контуром (Вт)
- **Δt_ln** — средняя логарифмическая разность температур (°C)
- **k** — коэффициент теплопередачи (Вт/(м²·К))
- **ε** — эффективность: ε = Q / Qmax

## 4) Математическая модель
1) Для вычисления выходных температур используется инженерная модель **ε-NTU**:

- C_h = m_h·cp_h, C_c = m_c·cp_c  
- C_min = min(C_h, C_c), Cr = C_min/C_max  
- UA = k·F, NTU = UA/C_min  
- Далее ε(NTU,Cr) для прямотока/противотока.

2) Тепловой поток:
- Q = ε·C_min·(T1 − T3)

3) Потери:
- Qх = (1 − loss)·Q

4) Выходные температуры:
- T4 = T1 − Q/C_h
- T2 = T3 + Qх/C_c

5) Контрольный расчёт по методике:
- k_calc = Qх / (F·Δt_ln)

## 5) Примечания по точности
- Теплоёмкость воды cp(T) берётся по табличным данным с линейной интерполяцией.
- Модель **не заменяет** реальный стенд: она предназначена для понимания влияния параметров и методики обработки измерений.
